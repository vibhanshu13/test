# --- Backward-lineage query: RAM / performance knobs ---

# Budget: ~2 GB blueprint cache + ~0.7 GB GVL/resolver projections
#         + ~0.5 GB path-planner prefetch + ~0.3 GB SQLite page cache
#         + ~0.5 GB runtime ≈ 4 GB steady-state, 7.5 GB hard backstop.

# Blueprint frame cache budget in MB (slots = budget // 15 MB → 2048 ≈ 136 slots).
# More slots = fewer Pass-2 blueprint reloads. Default is 1024 if unset.
